Self-Learning AI Chatbot Website.

A web-based AI chatbot that remembers you and learns from every conversation. It asks your name on the first visit, saves your details and preferences, and uses them to give more personal replies over time. To keep running without interruption
Features:
- Chat interface in the browser
- First-meeting questions (name and details) saved to memory
- Learns new facts about you from your messages
- Memory stored in storage.txt

Built with: Python, LangChain, Groq API, HTML, CSS, JavaScript, plain-text storage
